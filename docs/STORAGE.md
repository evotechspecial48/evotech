# Хранилище файлов: Облако Mail.ru

Основной объём файлов хранится в Облаке Mail.ru по протоколу WebDAV: проекты, рабочие модели, чертежи, договоры, итоговые архивы. В базе данных лежат только метаданные: имя, размер, контрольная сумма, привязка к проекту и этапу, журнал скачиваний.

## Структура папок в облаке

```
EvoTech/
  Проекты/
    12 МАФ — НОРЛАБ/
      01 ТЗ/
      02 Эскиз/
      03 3D-модель/      a1b2c3d4_модель.ifc
      04 Чертежи/
      05 Документация/
      06 Передача заказчику/
      Файлы проекта/     исходные данные, фото, документы без привязки к этапу
  Заявки/<номер>/
  Быстрые заказы/<номер>/Исходные данные | Архив
  Прочее/<год-месяц>/
```

Короткий префикс перед именем файла защищает от перезаписи одноимённых файлов.

Папки удобно просматривать прямо в облаке, но **переименовывать и перемещать файлы в облаке вручную нельзя**: сервис ищет файл по сохранённому пути. Загружайте файлы и удаляйте их через кабинет.

## Подключение

1. Проверьте тариф. Доступ по WebDAV в Облаке Mail.ru есть только на платных тарифах. Объём тарифа выбирайте под архив проектов: модели и комплекты КМД занимают десятки и сотни мегабайт.
2. Создайте пароль для приложения: Mail ID → «Безопасность» → «Пароли для внешних приложений» → «Добавить», доступ «Облако (WebDAV)». Пароль показывается один раз. Основной пароль от почты не подойдёт.
3. Пропишите параметры в `.env` на сервере:
   ```
   STORAGE_DRIVER=webdav
   WEBDAV_URL=https://webdav.cloud.mail.ru
   WEBDAV_USER=адрес@mail.ru
   WEBDAV_PASSWORD=пароль-приложения
   WEBDAV_ROOT=/EvoTech
   FILE_MAX_SIZE_MB=500
   ```
4. Перезапустите приложение и воркер. В «Настройки → Интеграции» должно отображаться «Облако по WebDAV».

Сервис работает с облаком сам, отдельная программа на сервере не нужна. Файлы скачиваются через сервис: права доступа и журнал продолжают работать, а наружу облако не открывается. Большие файлы передаются потоком, без загрузки в память сервера.

## Ограничения и рекомендации

- **Размер файла.** Лимит задаётся в «Настройки» (до 2000 МБ), по умолчанию 500 МБ. Файл при загрузке через сайт целиком проходит через память сервера, поэтому для файлов больше 500 МБ нужен сервер с 4 ГБ RAM и более.
- **Скорость.** Облако Mail.ru медленнее объектного хранилища. Временные сбои сервис переживает повторными попытками.
- **Перенос файлов.** Файлы, загруженные до переключения на облако, остались на локальном диске. Их нужно один раз перенести в облако по путям из базы (`FileAsset.storageKey`), а затем проверить скачивание.
- **Резервные копии.** Облако — единственное место хранения файлов. Ежедневные дампы базы с сервера складывайте в отдельную папку облака (`EvoTech/_backup`).
- **Тестирование.** Драйвер проверяется на любом WebDAV-сервере:
  ```bash
  docker run -d -p 8088:8080 rclone/rclone:1.68 serve webdav /data --addr :8080 --user tester --pass testpass123
  ```
  Затем запустите `npm test` с переменными `WEBDAV_TEST_URL`, `WEBDAV_TEST_USER` и `WEBDAV_TEST_PASSWORD`.

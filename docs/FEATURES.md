# Реализованные функции

## Публичная часть
- Посадочная страница: оффер и два CTA, направления, преимущества, этапы, примеры работ, интерактивный калькулятор предварительного расчёта, описание цифрового сервиса, показатели доверия, FAQ, контакты, подвал с юридическими документами.
- Страницы: услуги, примеры работ, процесс, быстрый заказ, заявка, о компании, контакты, политика конфиденциальности, согласие на обработку ПДн, вход, регистрация, восстановление пароля, приглашение, подтверждение почты.
- Формы: короткие, с состояниями загрузки, успеха и ошибки; защита от спама (honeypot, минимальное время заполнения, лимит по IP); согласие на обработку ПДн; UTM-метки и источник заявки; заявки сразу попадают в CRM.
- SEO: метаданные, Open Graph, JSON-LD (ProfessionalService и FAQPage), sitemap.xml, robots.txt.

## Доступ
- Регистрация и вход по почте, подтверждение почты, восстановление пароля, приглашение сотрудников и заказчиков.
- RBAC на пять ролей; проверки на сервере; изоляция данных; блокировка после неудачных попыток входа; задел под 2FA.

## CRM
- Заявки с сайта и из кабинета, ручная регистрация звонков; автоматическое назначение менеджера.
- Карточка: данные заказчика, UTM, комментарии (в том числе внутренние), задачи, файлы, история статусов.
- Список с фильтрами, поиском, сортировкой и пагинацией; канбан с переходом на следующий шаг; выгрузка CSV.
- Коммерческие предложения (позиции, PDF, версии, статусы); договор из шаблона с предпросмотром; конвертация в проект.

## ТЗ
- Поля по ТЗ заказчика, совместное редактирование с историей версий (автор, время, изменённые поля), черновик → проверка → уточнения → утверждение, неизменяемый снимок, вложения.

## Проекты
- Карточка: заказчик, договор, сроки, команда, общий процент готовности, лента событий, история статусов.
- Шесть этапов; версии результата с файлами и связью с предыдущей версией; внутренняя проверка; согласование заказчиком или возврат с обязательным комментарием; фиксация согласованной версии с контрольной суммой и проверкой целостности.
- Комментарии с упоминаниями @участника (уведомления), внутренние комментарии.
- Запросы заказчику с автоматической паузой таймера.
- Контроль обязательных результатов по этапам.
- AI-варианты конструкции по утверждённому ТЗ (демо).

## Таймер
- Календарные или рабочие дни с праздниками; автоматические и ручные паузы (дата, причина, инициатор, длительность); прогнозная дата; предупреждение о приближении срока и просрочке (уведомления от воркера); удаление записи о паузе только директором с записью в журнал.

## Файлы
- Загрузка нескольких файлов с прогрессом; категории; привязка к проекту, этапу и версии; предпросмотр изображений и PDF; белый список форматов (PDF, DOCX, XLSX, ZIP, JPG, PNG, DWG, DXF, IFC, STEP, STP) и лимит размера; антивирусная проверка (интерфейс); временные подписанные ссылки; журнал загрузок и скачиваний.

## Документы и договоры
- Шаблоны с версиями (редактирует директор), автозаполнение реквизитов, предпросмотр, PDF, версии договора, статусы, подписание простой ЭП (чекбокс и одноразовый код из письма) с фиксацией даты, IP, user-agent, пользователя, редакции и контрольной суммы.

## Быстрый заказ
- Пошаговый мастер с валидацией, загрузка фото участка, очередь AI-задач со статусами и повторным запуском, три варианта эскиза (SVG), выбор варианта, типовой договор, оплата, итоговый ZIP-архив (эскизы, визуализация, 3D-модель IFC, чертежи PDF, спецификация и ведомость CSV, пояснительная записка PDF), правила доступа к архиву.

## Платежи
- Т-Банк (Init, подпись, webhook с проверкой подписи и идемпотентностью, отмена/возврат) и встроенный демо-банк; история оплат; карты не хранятся.

## Уведомления, аналитика, журнал, настройки
- Внутренние уведомления и почта для всех событий из ТЗ; надёжная очередь писем.
- Аналитика: новые заявки, конверсия, источники, проекты по статусам, загрузка проектировщиков, средняя длительность этапов, возвраты на доработку, риск просрочки, платежи, быстрые заказы.
- Журнал действий с фильтром и пагинацией.
- Настройки: режим таймера, лимит размера файлов, праздники, реквизиты, шаблоны документов, статус интеграций.
- Профиль: выгрузка своих ПДн; обезличивание пользователя директором.

## Интерфейс
- Дизайн-система на токенах (цвета, типографика, радиусы); адаптивная вёрстка; статус всегда показан текстом и значком, а не только цветом; таблицы прокручиваются внутри контейнера; пустые состояния, skeleton-загрузка, страница ошибки, подтверждение опасных действий; фокус-индикаторы, ссылка «перейти к содержимому», ARIA-атрибуты, учёт `prefers-reduced-motion`.

## Критерии приёмки — как проверено

| Критерий | Проверка |
|---|---|
| Каждая роль видит только разрешённое | Юнит-тесты RBAC и доступа; интеграционный тест изоляции; ручная проверка меню и маршрутов проектировщика |
| Публичная заявка появляется у менеджера | Отправлена форма с UTM → заявка №8 у sales@, уведомление создано |
| Воронка и создание проекта | Интеграционный тест: заявка → договор → подписание → проект |
| Совместное ТЗ с версиями | Интеграционный тест: версии от заказчика, менеджера и РП, снимок |
| Новая версия и отправка на проверку | Интеграционный тест и ручная проверка в браузере (проект №3) |
| Согласование или возврат с комментарием | Интеграционный тест и ручная проверка (проект №2) |
| Пауза и возобновление таймера | Юнит-тесты таймера; интеграционный тест; ручная проверка |
| История согласований, пауз, статусов, файлов | `Approval`, `TimerPause`, `StatusChange`, `AuditEvent`; вкладки проекта |
| Быстрый заказ до выбора варианта | Ручная проверка в браузере и интеграционный тест |
| Оплата недоступна до подтверждения договора | Юнит-тест `canPay`; интеграционный тест; кнопка неактивна, причина показана |
| Архив недоступен до выполнения условий | Юнит-тест `canDownloadResult`; интеграционный тест; API отдаёт 403 с причинами |
| Адаптивность, состояния | Проверено при ширине 800 и 1024 px |
| Запуск по README | `npm install` → `db:up` → `migrate deploy` → `db:seed` → `dev` |
| Тесты критичных сценариев | `npm test`: 56 тестов |

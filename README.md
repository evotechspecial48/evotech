# EvoTechnology — сервис проектирования металлоконструкций (MVP)

Веб-приложение компании EvoTechnology: рекламная посадочная страница и личный кабинет, который автоматизирует путь от заявки до сдачи проекта. В кабинете ведутся CRM, техническое задание с версиями, этапы проектирования и согласования, таймер срока с паузами, файлы, договоры с подписанием по коду, оплата через Т-Банк и быстрые заказы малых конструкций с AI-генерацией. Сейчас AI работает через демонстрационный провайдер.

## Стек

| Слой | Технологии |
|---|---|
| Интерфейс | Next.js 15 (App Router, Server Components, Server Actions), React 19, TypeScript, Tailwind CSS 4 |
| Сервер | Next.js route handlers и server actions, сервисный слой `src/services` |
| Данные | PostgreSQL 17, Prisma 6 (схема и миграции в `prisma/`) |
| Фоновые задачи | Очередь в БД (AI-задачи, письма, сроки) и воркер `scripts/worker.ts` |
| Интеграции | `AIProvider` (Mock / Claude), `PaymentProvider` (демо-банк / Т-Банк), SMTP (Mailpit в dev), файловое хранилище (локальное / S3) |
| Тесты | Vitest: юнит-тесты домена и интеграционные сквозные сценарии на реальной БД |
| Инфраструктура | Docker Compose: `db`, `mailpit`, профиль `app` (приложение и воркер) |

## Быстрый старт (разработка)

Нужно: Node.js 22+ (проверено на 24), Docker Desktop.

```bash
npm install
cp .env.example .env            # затем задайте APP_SECRET (openssl rand -hex 32)
npm run db:up                   # PostgreSQL :5432 и Mailpit :8025/:1025
npx prisma migrate deploy       # применить миграции
npm run db:seed                 # демо-данные (пересоздаёт все данные в БД!)
npm run dev                     # http://localhost:3000
npm run worker                  # во втором терминале: фоновые задачи
```

Письма (подтверждение почты, коды подписания договора, уведомления) приходят в **Mailpit: http://localhost:8025**.

Без воркера приложение тоже работает: AI-задачи запускаются прямо в веб-процессе. Воркер добирает задачи после перезапуска, повторяет недоставленные письма и рассылает предупреждения о сроках.

### Полный запуск в Docker

```bash
docker compose --profile app up --build
npm run db:seed                 # по желанию: демо-данные (с хоста, БД доступна на :5432)
```

Демо-сценарии (`prisma/seed.ts`):

1. **Новая заявка** — №1 с сайта с UTM-метками, ещё одна — в квалификации.
2. **Заявка на этапе подготовки ТЗ** — две версии ТЗ от заказчика и менеджера, запрошены уточнения.
3. **Проект с приостановленным таймером** — №1, открыт запрос заказчику, в истории есть завершённая пауза.
4. **Эскиз на согласовании** — №2, версия 1 прошла внутреннюю проверку и ждёт решения заказчика.
5. **Проект, возвращённый на доработку** — №3, замечания заказчика к 3D-модели.
6. **Завершённый и оплаченный быстрый заказ** — №1: договор подписан, оплата прошла, архив доступен.
7. Дополнительно: договор Д-2026-0003 ждёт подписания кодом, а у второго заказчика есть свой проект для проверки изоляции.

## Команды

| Команда | Назначение |
|---|---|
| `npm run dev` / `build` / `start` | Разработка / сборка / production-сервер |
| `npm run worker` | Фоновый воркер |
| `npm run lint` · `npm run typecheck` | ESLint · проверка типов |
| `npm test` | Юнит- и интеграционные тесты (интеграционные используют отдельную БД `evotech_test`; если PostgreSQL не запущен, они пропускаются) |
| `npm run db:up` / `db:down` | Запуск и остановка PostgreSQL и Mailpit |
| `npm run db:migrate` | Новая миграция при изменении схемы |
| `npm run db:seed` | Пересоздать демо-данные |
